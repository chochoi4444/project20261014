# 원본액 자동입력

분기마다 보유펀드별 기준가격대장(신탁재산명세부)에서 **원본액**을 찾아 대상 엑셀의 `원본액` 열에 옮겨 적던 작업을 자동화하는 브라우저 도구입니다. [총자산 자동입력](../nav-total-assets/README.md)과 같은 화면·펀드명 매칭 엔진을 쓰고, 읽는 계정과 채우는 열만 다릅니다.

- 원본액: 계정과목 `원본액`(원본합계·원본총계·원본·신탁원본 표기도 인정) 줄의 **전일 대변잔액**. `전일차변 | 전일대변`으로 나뉜 머리글, `전일잔액` 병합 머리글 + 아랫줄 `차변 | 대변` 양식 모두 읽습니다.
- 같은 줄의 당일 잔액은 넣지 않고, 전일과 다르면 그 차이를 참고로 보여 줍니다. 원본액 계정이나 전일 대변 칸이 없으면 다른 값으로 대신하지 않고 비워 둡니다.
- 투자회사(`투자회사`·`투융자회사`)는 원본액 대신 `잔존좌수`(발행주식수)를 넣고 **검토**로 표시합니다.
- 탭 이름이 `1종`·`2종`·`Class`처럼 종류를 나타내는 파일은 탭마다 장부를 따로 만듭니다(예: `운용 / 1종 / 2종`).
- 대상 엑셀: ‘종목명(펀드명)’과 ‘원본’이 들어간 머리글(`원본액`, `원본액(2026.09.30)` 등), 없으면 `발행주식수(출자금총액)` 머리글이 같은 줄에 있는 시트를 찾습니다.
- 펀드명 매칭(코사인 유사도·호수·사명 규칙), 결산전/결산후, 탭이 여러 개인 파일, 매핑 내보내기·가져오기는 총자산 도구와 같습니다.
- 원본 엑셀은 원본액 칸의 값만 바꾸고 서식·다른 시트는 그대로 둔 채 `원본이름_원본액입력.xlsx`로 저장합니다.
- 모든 처리는 브라우저 안에서 일어나며 파일이 외부로 전송되지 않습니다.

## 파일 구성

| 경로 | 내용 |
| --- | --- |
| `src/app.html` | 도구 본체 (claude.ai 아티팩트로 배포되는 페이지) |
| `build.mjs` | 라이브러리를 HTML 하나에 넣은 오프라인판 생성 (`npm run build` → `dist/원본액자동입력_오프라인.html`) |
| `tests/principal.test.mjs` | 원본액(전일 대변잔액) 산출 회귀 테스트 (가상 시산표) |
| `tests/matching.test.mjs` | 펀드명 매칭 회귀 테스트 (총자산 도구와 같은 케이스) |
| `tests/e2e.mjs` | 실제 장부로 끝까지 돌려 보는 점검 (`TARGET=대상.xlsx LEDGERS=장부폴더 npm run e2e`) |

## 점검

```bash
cd nav-principal
npm install
npm test
```

## 아직 없는 것

총자산 도구에 있는 파이썬판·Windows exe·엑셀 매크로판(VBA)은 이 도구에는 아직 없습니다.
