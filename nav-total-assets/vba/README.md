# 총자산 자동입력 — 엑셀 매크로판

HTML·exe 파일을 사내(오프라인 망)로 가져갈 수 없을 때 쓰는 판입니다. **`TotalAssets.bas` 한 파일의 텍스트를 복사해 엑셀에 붙여 넣으면** 됩니다. 라이브러리·설치·인터넷이 필요 없고, 웹·파이썬판과 같은 규칙으로 같은 결과를 냅니다.

## 설치 (처음 한 번)

1. 엑셀에서 **새 통합문서**를 엽니다.
2. **Alt + F11** → VBA 편집기에서 **삽입 → 모듈**.
3. `TotalAssets.bas`의 **내용 전체**를 복사해 빈 모듈 창에 붙여 넣습니다. (첫 줄이 `Option Explicit`)
4. 메뉴 **디버그 → VBAProject 컴파일**을 눌러 오류가 없는지 확인합니다.
5. **다른 이름으로 저장 → `Excel 매크로 사용 통합 문서 (*.xlsm)`**, 예: `총자산자동입력.xlsm`.

> 매크로가 막혀 있으면: 파일 → 옵션 → 보안 센터 → 매크로 설정에서 허용하거나, 파일을 ‘신뢰할 수 있는 위치’에 두세요. 사내 정책에 따라 IT 부서 확인이 필요할 수 있습니다.

## 실행

1. `총자산자동입력.xlsm`을 열고 **Alt + F8 → `RunTotalAssets` → 실행**. (버튼을 만들어 연결해도 됩니다)
2. 총자산을 채울 **대상 엑셀**을 고릅니다. 이 파일은 닫혀 있어야 합니다.
3. **기준가격대장 폴더**를 고릅니다. 하위 폴더까지 읽습니다 (`.xlsx` `.xls` `.xlsm` `.xlsb` `.csv`).
4. **기준일**을 확인합니다. 대상 엑셀 머리글 ‘총자산 (2026.06.30 기준)’에서 읽은 값이 들어 있습니다.
   장부 날짜와 다르면 “기준일을 바꿔 다시 판정할까요?”라고 묻습니다.
5. ‘검토’ 행이 있으면 함께 입력할지 묻습니다. 기본은 ‘아니오’(자동·수동 행만 입력).
6. 대상 엑셀과 같은 폴더에 두 파일이 생깁니다.
   - `대상이름_총자산입력.xlsx` — 총자산을 채운 파일 (원본은 그대로)
   - `대상이름_매칭결과.xlsx` — 행별 매칭 근거(상태별 색), 장부별 추출값

## 매칭이 틀리거나 못 찾을 때

매크로가 든 통합문서(`총자산자동입력.xlsm`)에 **`매핑`** 시트를 만들고 1행은 머리글, 2행부터 적습니다.

| A열: 대상 엑셀 종목명 | B열: 기준가격대장 펀드명 또는 파일명 |
| --- | --- |
| 가온대체투자블랙락전문투자형사모73호 | 가온대체투자블랙락73호CLO |
| 매칭하지 않을 종목명 | 없음 |

띄어쓰기·괄호 차이는 무시합니다. `_매칭결과.xlsx`의 ‘장부 펀드명’ 열 값을 복사해 쓰면 됩니다.

## 동작 규칙 (웹·파이썬판과 같음)

- 펀드명 유사도: 코사인 유사도(글자 1~3gram, TF-IDF) 60% + 글자 순서 일치율 40%. 호수·종류 숫자가 다르면 다른 펀드.
- 총자산: `신탁재산총자산` 계정 → `순자산총액 + 부채` → `자산합계` 순. `총자산 = 순자산 + 부채`로 교차검증.
- 자동: 유사도 0.85 이상 & 2순위와 0.08 이상 차이(또는 0.75 이상 & 0.40 이상 차이), 검증 통과, 기준일 일치.
- 기준가격대장은 읽기 전용으로 열고, 그 파일의 매크로·외부 링크는 실행하지 않습니다. 이미 열어 둔 장부는 닫지 않습니다.

## 검증

`tests/run_lo_tests.py`가 매크로의 계산부(펀드명 매칭, 장부 읽기, 총자산 산출, 행별 판정)를 LibreOffice의 VBA 호환 모드로 실행해 파이썬판과 대조합니다.

```bash
python tests/run_lo_tests.py                                   # 매칭 엔진 704쌍 + 가상 장부
TARGET=대상.xlsx LEDGERS=장부폴더 BASE=2026-09-30 python tests/run_lo_tests.py   # 실제 파일 추가
```

- 매칭 엔진: 가상 펀드명 32×22쌍의 점수·근거·배정·상태가 파이썬판과 모두 같음
- 받은 실제 장부 3개: 장부별 인식값(펀드명·운용사·기준일·총자산·산출근거·검증)과 행별 판정이 모두 같음

엑셀 전용 부분(파일 고르기·열기·저장·결과 통합문서 만들기)은 이 작업 환경에 엑셀이 없어 실행해 보지 못했습니다. 처음 한 번은 받은 장부로 직접 실행해 금액을 확인하세요.

## 참고

- 코드에 한글이 들어 있어 **한국어 Windows**의 엑셀에서 붙여 넣어야 글자가 깨지지 않습니다.
- 문서보안(DRM)이 걸린 장부는 ‘파일을 열 수 없습니다’로 표시됩니다.
- 장부가 많으면 읽는 데 시간이 걸립니다(상태 표시줄에 진행 상황이 나옵니다).
