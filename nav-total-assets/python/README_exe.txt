총자산 자동입력 (Windows 실행 파일)
=====================================

기준가격대장(엑셀)에서 총자산을 찾아 대상 엑셀의 '총자산' 칸에 입력합니다.
설치가 필요 없고, 파일은 이 PC 안에서만 처리됩니다 (인터넷 연결 불필요).

■ 쓰는 법
 1. TotalAssetsFiller.exe 를 더블클릭합니다.
 2. ① 대상 엑셀 : '파일 선택…'으로 총자산을 채울 엑셀(예: 구조화기업 명세)을 고릅니다.
    → 기준일이 머리글 '총자산 (2026.06.30 기준)'에서 자동으로 채워집니다. 분기가 다르면 고쳐 적으세요.
 3. ② 기준가격대장 : '폴더 선택…'으로 장부가 모여 있는 폴더를 고릅니다 (하위 폴더까지 읽음).
 4. '실행'을 누르면 대상 엑셀과 같은 폴더에 두 파일이 생깁니다.
      대상이름_총자산입력.xlsx  - 총자산을 채운 엑셀 (원본은 그대로)
      대상이름_매칭결과.csv     - 행마다 어느 장부에서 얼마를 가져왔는지 근거
 5. 화면 표에서 결과를 확인합니다.
      자동   : 펀드명이 충분히 비슷하고 기준일까지 맞아 입력됨
      검토   : 유사도가 낮거나 기준일·검증이 맞지 않음 → 확인 후 '검토 행도 입력'을 켜고 다시 실행
      미매칭 : 맞는 장부가 없음 (PEF·비상장주식 등은 보통 여기에 남음)
      제외   : 총자산 칸에 '제외'가 적힌 행 (건드리지 않음)

■ 매칭이 틀리거나 못 찾을 때
 메모장으로 아래처럼 JSON 파일을 만들어 '펀드명 매핑 (선택)'에 지정하고 다시 실행합니다.
   {
     "대상 엑셀의 종목명": "기준가격대장의 펀드명 또는 파일명",
     "매칭하지 않을 종목명": null
   }
 매칭결과.csv 의 '매핑키(장부)' 열 값을 그대로 복사해 쓰면 됩니다.
 웹 도구에서 '매핑 내보내기'로 받은 파일도 그대로 쓸 수 있습니다.

■ 웹 화면 한 파일 (TotalAssetsFiller-offline.html)
 exe와 같은 기능을 브라우저로 쓰는 파일입니다. 인터넷 없이 크롬·엣지로 열면 됩니다.
 파일 하나라 메신저로 공유하기 쉽습니다. 장부 파일은 PC 밖으로 나가지 않습니다.

■ 명령창으로 일괄 처리 (TotalAssetsFiller-cli.exe)
   TotalAssetsFiller-cli.exe 대상.xlsx 장부폴더 --base-date 2026-09-30
   옵션: --include-review  --overwrite  --mapping 매핑.json  -o 결과.xlsx  --dry-run

■ 알아 둘 점
 - 문서보안(DRM)이 걸린 엑셀은 읽을 수 없습니다. 해제된 사본을 쓰세요.
 - 결과 파일이 엑셀에서 열려 있으면 저장할 수 없습니다. 닫고 다시 실행하세요.
 - 서명되지 않은 실행 파일이라 처음 실행할 때 Windows SmartScreen 경고가 뜰 수 있습니다
   ('추가 정보' → '실행'). 사내 보안 프로그램이 막으면 IT 부서에 허용을 요청하세요.
