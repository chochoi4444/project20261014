# AI 바이브코딩 교육 사전 준비 가이드

**과제:** 비정형 보고서 취합 에이전트 (자산운용부, 기획서 1안)
**목표:** Claude Code로 하루 안에 **동작하는 웹앱 PoC** 만들기

> ⚠️ **먼저 확인할 것 (보안)**
> 기획서와 함께 올린 엑셀 3개(운용사 기준가격대장 2종, 2026 2Q 수익증권 평가 양식)에는 **실제 펀드명, 금액, 법인번호**가 들어 있습니다.
> 이 파일들은 **교육장에 가져가거나 Claude Code에 올리면 안 됩니다.** 이 가이드에서는 *양식 구조(컬럼, 계정코드 체계)만* 참고했고, 숫자와 이름은 모두 가상으로 바꿨습니다.

---

## 0. 과제 한 줄 정리 (Claude Code에 처음 설명할 문장)

> "운용사마다 **양식이 다른 기준가격대장(엑셀)** 여러 개를 올리면, 각 파일에서 **총자산** 등 요청값을 찾아 **당사 수익증권 평가 양식의 해당 종목 행에 자동으로 채워 주고**, 못 찾았거나 의심스러운 값은 표시해 주는 웹앱"

| 구분 | 내용 |
|---|---|
| 입력 | ① 운용사별 기준가격대장 엑셀 N개 (양식 제각각) ② 당사 양식(빈 칸 있음) ③ 종목↔펀드 매핑표 |
| 처리 | 파일 판별 → 양식 인식 → 값 추출 → 종목 매칭 → 검증 |
| 출력 | 값이 채워진 당사 양식 엑셀 다운로드 + 처리 결과표(성공/경고/누락) |
| PoC 범위 | 엑셀 3가지 양식에서 **총자산 1개만** 추출·기입 (나머지 집계는 내부에서 피벗으로 처리하므로 범위 밖) |

## 1. 준비해야 할 데이터 항목

### 1-1. [입력] 운용사 기준가격대장: 3가지 양식으로 준비

실제 자료를 보면 운용사마다 **위치·코드·헤더가 전부 다릅니다.** 이게 바로 "비정형"의 핵심이므로 **서로 다른 양식 3종**을 준비합니다.

**공통으로 뽑아야 하는 값 (논리 항목)**

| 논리 항목 | 데이터 타입 | 단위 | 필수 | 설명 |
|---|---|---|---|---|
| 기준일(작업일자) | date (YYYY-MM-DD) | - | ✅ | 당사 양식 기준일과 같아야 함 |
| 펀드코드 | string | - | ✅ | 매핑 키 1순위 |
| 펀드명 | string | - | ✅ | 매핑 키 2순위 (파일명에만 있는 경우도 있음) |
| 자산합계(총자산) | integer | 원 | ✅ | **이번 PoC의 핵심 추출값** |
| 부채합계 | integer | 원 | ✅ | 검증용 |
| 순자산총액 | integer | 원 | ✅ | 검증용 |
| 좌수 | integer | 좌 | ⭕ | 검증용 (기준가 역산) |
| 기준가 | decimal(10,2) | 원/1,000좌 | ⭕ | 검증용 |

**양식별 구조 (실제 자료의 '모양'만 본뜸)**

| 양식 | 모양 | 총자산 위치 | 함정 |
|---|---|---|---|
| **A**: 좌우형 대장 | 상단에 `작업일자 ▶`, `펀 드 명 ▶` / 표는 차변(당일잔액·당일증감액·전일잔액), 코드, 계정명, 대변(전일·증감·당일) | 코드 `100000` · 계정명 `자산합계` · **차변 당일잔액** | 헤더가 2줄, 앞쪽 빈 행·열 |
| **B**: 한 줄 헤더 표 | `계정구분, 당일차변잔액, 차변금액, 전일차변잔액, 계정코드, 계정과목명, 전일대변잔액, 대변금액, 당일대변잔액` | 코드 `1000000000` · 계정명 `[[ 자산 ]]` · **당일차변잔액** | 펀드명·기준일이 **파일명에만** 있음, 계정명에 괄호/공백 |
| **C**: 운용보고서 요약 | `구분 / 금액` 세로 나열, `(단위: 백만원)` | `총자산(AUM)` 행 | **단위 변환(×1,000,000)**, 날짜가 `2026년 6월 30일` 형식 |

## 2. 핵심 업무 규칙 (Logic) · 조건 · 계산식

### 2-1. 처리 흐름

```
[파일 업로드] → ① 양식 판별 → ② 값 추출 → ③ 단위/형식 정규화 → ④ 종목 매칭 → ⑤ 검증 → ⑥ 양식에 기입 → [다운로드]
```

### 2-2. 규칙표

| # | 단계 | 규칙 | 조건 / 계산식 |
|---|---|---|---|
| R1 | 양식 판별 | 시트 안의 '표식 단어'로 양식 A/B/C 결정 | `작업일자 ▶` 있음 → A / `계정과목명` + `[[ 자산 ]]` → B / `(단위: 백만원)` 또는 `총자산(AUM)` → C / 전부 아님 → "미인식" |
| R2 | 총자산 추출 | 양식별 '앵커' 행을 찾아 정해진 열 값 사용 | A: 코드=`100000` 행의 차변 당일잔액 · B: 코드=`1000000000` 행의 당일차변잔액 · C: `총자산` 포함 행의 금액 |
| R3 | 앵커 대체 | 코드로 못 찾으면 계정명 키워드로 다시 찾기 | 키워드: `자산합계`, `[[ 자산 ]]`, `총자산`, `AUM` (공백·괄호 제거 후 비교) |
| R4 | 단위 정규화 | 모든 금액을 **원 단위 정수**로 | `백만원` → ×1,000,000 / `천원` → ×1,000 / 콤마·공백 제거 / 음수 `(123)` 표기 → -123 |
| R5 | 날짜 정규화 | 모든 날짜를 `YYYY-MM-DD`로 | `2026년 6월 30일`, `260630`(파일명), `20260630` 모두 처리 |
| R6 | 펀드 식별 | 펀드코드 → 펀드명 → 파일명 순서로 찾기 | 양식 B는 파일명에서 운용사·펀드명·날짜 파싱 |
| R7 | 종목 매칭 | 매핑표로 **펀드코드 → 표준코드 → 당사 행** 연결 | 1순위 코드 일치 / 2순위 종목명 정규화 일치(`(주)`·공백·특수문자 제거) / 3순위 유사도 ≥ 0.85면 **"확인필요"로 기입** |
| R8 | 기준일 일치 | 보고서 기준일 ≠ 당사 기준일이면 기입은 하되 경고 | `report_date != base_date` → 비고 "기준일 불일치(보고서: …)" |
| R9 | 제외 대상 | 실제 양식 하단 주석의 제외 기준 그대로 적용 | 유가증권분류·구조화기업성격이 **MMF/ETF**, **상장주식**, **신종유가증권/초기투자자금**이면 총자산 = `"제외"` (퇴직·퇴연 계정은 **포함**) |
| R10 | 누락 처리 | 매핑표에는 있는데 파일이 없음 | 총자산 빈칸 + 비고 "보고서 미수령" + 결과 화면에 빨간 표시 |
| R11 | 검증식 ① | 대차 일치 | `|자산합계 − 부채합계 − 순자산총액| ≤ 1원` → 아니면 "검증실패" |
| R12 | 검증식 ② | 기준가 역산 | `|순자산총액 ÷ 좌수 × 1,000 − 기준가| ≤ 0.01` (값이 있는 경우만) |
| R13 | 덮어쓰기 금지 | 이미 값이 있는 칸은 바꾸지 않음 | 기존 값 ≠ 추출 값이면 비고에 "기존값 상이"만 기록 |

### 2-3. 결과 상태값 (화면 표시용)

| 상태 | 의미 | 색 |
|---|---|---|
| ✅ 완료 | 추출·매칭·검증 모두 통과 | 초록 |
| ⚠️ 확인필요 | 유사도 매칭, 기준일 불일치, 변동 큼 | 노랑 |
| ❌ 실패 | 양식 미인식, 검증식 불일치, 값 없음 | 빨강 |
| ➖ 제외 | 규칙 R9 해당 | 회색 |
| ⏳ 미수령 | 규칙 R10 해당 | 회색 |

## 4. 외부 API · 공공데이터 필요 여부

| 항목 | 필요 여부 | 이유 |
|---|---|---|
| 공공데이터 / 금융 API | ❌ **불필요** | 운용사 보고서는 비공개 자료라 공공데이터로 대체할 수 없음. 더미로 충분 |
| LLM API (Claude API) | 🔺 **선택** | 규칙(R1~R3)으로 못 읽는 낯선 양식만 LLM에게 "총자산 셀을 찾아줘"라고 물어보는 **보조 수단** 정도로 활용 가능. 키 발급이 안 되면 생략해도 PoC는 완성됨 |
| 이메일/포탈 연동 | ❌ 제외 | 1일 범위 밖. 파일 업로드로 대체 |

> 💬 **기획서 질의사항("내부망에서 활용 가능한가?")에 대해:** 위 규칙 기반 방식(R1~R13)은 **인터넷 없이 로컬 Python만으로 동작**하므로, 더미로 만든 로직을 내부망에 그대로 가져가 실데이터에 적용하기 좋습니다. LLM 보조 기능을 쓰는 경우에만 내부망 반입 여부(사내 승인된 AI 사용 가능 여부)를 별도로 확인해야 합니다.

## 5. 더미데이터 생성 가이드

### 방법 A: 준비된 스크립트 실행 (권장, 1분)

```bash
pip install openpyxl
python scripts/make_dummy_data.py
```

생성 결과:

```
dummy_data/
```

일부러 넣어 둔 **테스트 케이스**:

| 보고서 미수령 | 감마 세컨더리 PEF 3호 | R10 |

### 방법 B: Claude Code에게 직접 만들어 달라고 하기

교육 당일 바로 쓸 수 있는 프롬프트:

```
자산운용사 '기준가격대장' 더미 엑셀을 만들어줘. 실제 회사명/펀드명은 쓰지 말고 가상 이름을 써.
- 양식 A: 상단에 '작업일자 ▶', '펀 드 명 ▶' / 차변(당일잔액, 당일증감액, 전일잔액) | 코드 | 계정명 | 대변(전일잔액, 당일증감액, 당일잔액)
  요약코드: 100000 자산합계, 200000 부채합계, 300000 원본합계, 700001 순자산총액, 700003 좌수, 700004 기준가
- 양식 B: 한 줄 헤더(계정구분, 당일차변잔액, 차변금액, 전일차변잔액, 계정코드, 계정과목명, 전일대변잔액, 대변금액, 당일대변잔액),
  자산은 '[[ 자산 ]]'(코드 1000000000), 펀드명은 파일명에만 넣기
- 양식 C: '구분/금액' 세로 표, 단위 백만원
- 숫자는 자산합계 − 부채합계 = 순자산총액, 순자산총액 ÷ 좌수 × 1000 = 기준가가 맞도록
```
